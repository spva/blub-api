Этот проект предоставляет окружение на базе Docker для запуска приложения Symfony.

## Начало работы

### 1. Инициализация проекта

Запустите скрипт инициализации для настройки окружения:

```bash
./init-project.sh
```

Этот скрипт выполнит:
- Сборку Docker-образов
- Установку зависимостей Composer
- Настройку переменных окружения

### 2. Основные команды Makefile

Используйте предоставленный `Makefile` для выполнения основных задач:

- **Запуск контейнеров:**
    ```bash
    make up
    ```
- **Остановка контейнеров:**
    ```bash
    make down
    ```
- **Установка зависимостей Composer:**
    ```bash
    make composer-install
    ```
- **Выполнение команд Symfony console:**
    ```bash
    make console CMD="your:command"
    ```
- **Запуск тестов:**
    ```bash
    make test
    ```

### 3. Доступ к приложению

После запуска контейнеров приложение будет доступно по адресу [http://localhost:8000/](http://localhost:8000/).

## Дополнительная информация

- Все команды следует выполнять из корневой директории проекта.
- Убедитесь, что Docker и Docker Compose установлены на вашем компьютере.
